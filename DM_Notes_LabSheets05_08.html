LAB SHEET 05

Permutations & Combinations

Core Concept

Both deal with counting selections from a set, but differ in one critical way: order.

PERMUTATION

Counting arrangements — order matters.

(A, B) and (B, A) are two different permutations.

COMBINATION

Counting selections — order does not matter.

(A, B) and (B, A) are the same combination.

Formulas

Permutation — nPr

Number of ways to arrange r objects from n distinct objects.

nPr = n! / (n − r)!

Example: 3P2 = 3! / 1! = 6

Combination — nCr

Number of ways to choose r objects from n distinct objects.

nCr = n! / [r! × (n − r)!]

Example: 3C2 = 3! / (2! × 1!) = 3

Permutation with Identical (Indistinguishable) Objects

When some objects are identical, divide out the duplicate arrangements:

= n! / (a! × b! × c! × …)

Example: arranging AABBC → 5! / (2! × 2! × 1!) = 30

Stars and Bars (Distributing identical items)

Ways to distribute n identical items into k distinct categories (repetition allowed):

C(n + k − 1, k − 1)

Example: allocate 10 VMs across 4 types → C(13, 3) = 286

Key Python Code Patterns

Generate & count permutations

from itertools import permutations

actors = ["A", "B", "C"]
all_perms = list(permutations(actors))
print(len(all_perms))          # 6
print(all_perms[4])            # 5th schedule (index 4)

# Convert tuple to string
perms_str = ["".join(p) for p in all_perms]

Passwords — product (repetition allowed)

from itertools import product
import math

letters = ["a", "b", "c", "d"]
digits  = ["0", "1", "2", "3", "4"]

letter_part = list(product(letters, repeat=2))
digit_part  = list(product(digits, repeat=3))

passwords = [l + d for l in letter_part for d in digit_part]
print(len(passwords))   # 4² × 5³ = 2000

Combinations — committee formation

from itertools import combinations

employees = ["A", "B", "C", "D"]
committees = list(combinations(employees, 2))
print(committees[2])     # 3rd committee (index 2)

math.comb — direct formula

import math
print(math.comb(6, 3))   # 20
print(math.comb(15, 11)) # C(15,11) = 1365

Indistinguishable objects — manual formula

import math
# 7 books: 3 red, 2 green, 1 blue, 1 orange
unique = math.factorial(7) // (math.factorial(3) * math.factorial(2))
print(unique)   # 420

Combinations with replacement — bouquets

from itertools import combinations_with_replacement

flowers = ["Rose", "Lily", "Tulip"]
bouquets = list(combinations_with_replacement(flowers, 3))

# Filter bouquets with all different flowers
all_diff = [b for b in bouquets if len(set(b)) == 3]

LAB SHEET 06

Recursion

What is Recursion?

A function that calls itself to solve a problem by breaking it into smaller, simpler subproblems. Every recursive function must have:

Base Case

The stopping condition. Without it, the function recurses infinitely and causes a stack overflow.

Example: if n == 0: return 1

Recursive Case

Where the function calls itself with a modified (smaller) parameter, moving toward the base case.

Example: return n * factorial(n-1)

Classic Recursive Functions

1 · Factorial

f(n) = n × f(n−1) | base: f(0) = 1
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)
print(factorial(5))  # 120

2 · Fibonacci

F(n) = F(n−1) + F(n−2) | base: F(0)=0, F(1)=1
def Fibo(n):
    if n <= 1:
        return n
    return Fibo(n - 1) + Fibo(n - 2)
print(Fibo(6))  # 8  (sequence: 0,1,1,2,3,5,8)

3 · Sum of Natural Numbers

S(n) = n + S(n−1) | base: S(0) = 0 or S(1) = 1
def S(n):
    if n == 0: return 0
    return n + S(n - 1)
print(S(5))   # 15

4 · Harmonic Sum

H(n) = 1/n + H(n−1) | base: H(1) = 1
def harmonic_sum(n):
    if n == 1: return 1
    return 1/n + harmonic_sum(n - 1)
print(round(harmonic_sum(5), 4))  # 2.2833

5 · Sum of Digits

sum_digits(n) = n%10 + sum_digits(n//10) | base: n==0 → 0
def sum_of_digits(n):
    if n == 0: return 0
    return n % 10 + sum_of_digits(n // 10)
print(sum_of_digits(1234))  # 10

6 · GCD (Euclidean Algorithm)

gcd(a,b) = gcd(b, a mod b) | base: b==0 → return a
def gcd(a, b):
    if b == 0: return a
    return gcd(b, a % b)
print(gcd(48, 18))  # 6

7 · Pascal's Triangle

pascal(n,k) = pascal(n−1,k−1) + pascal(n−1,k) | base: k==0 or k==n → 1
def pascal(n, k):
    if k == 0 or k == n: return 1
    return pascal(n - 1, k - 1) + pascal(n - 1, k)

8 · Sum of Even Numbers

def sum_even(n):
    if n == 0: return 0
    return n + sum_even(n - 2)
print(sum_even(8))  # 2+4+6+8 = 20

9 · Sum of Factorials

def sum_factorials(n):
    if n == 0: return 0
    return factorial(n) + sum_factorials(n - 1)
print(sum_factorials(4))  # 1!+2!+3!+4! = 1+2+6+24 = 33

Recursion Tips

TIP Always define the base case first. Trace small inputs manually (n=0,1,2) to verify correctness before testing large values.
WATCH OUT Missing base case → infinite recursion → RecursionError. Each recursive call uses memory on the call stack.

What is a Graph?

A non-linear data structure made of vertices (nodes) connected by edges (links). Used to model networks, routes, relationships.

import networkx as nx
import matplotlib.pyplot as plt

G = nx.DiGraph()
G.add_edges_from([
    ('A','B'), ('B','C'), ('C','D'),

for node in G.nodes():

Key Concepts Summary

Self-loop

An edge where both endpoints are the same node: G.add_edge(1,1)

Degree

Number of edges connected to a node. Directed graphs have separate in-degree and out-degree.

Cycle

A path that starts and ends at the same node without repeating any node/edge.

Simple Path

A path between two nodes where no node is repeated.

Trees, MST, BFS & DFS

What is a Tree?

A tree is a special graph that is connected and acyclic (no cycles). Exactly one unique path exists between any two nodes.

KEY FACT All trees are graphs, but not all graphs are trees. A tree with n nodes always has exactly n − 1 edges.

Tree in NetworkX

import networkx as nx
import matplotlib.pyplot as plt

T = nx.DiGraph()
T.add_edges_from([
    (10,20), (10,30), (20,40),
    (20,50), (30,60), (30,70), (70,80)
])

# Check if valid tree
print(nx.is_tree(T))              # True

# Get children of node 20
print(list(T.successors(20)))     # [40, 50]

# Get parent of node 40
print(list(T.predecessors(40)))  # [20]

# Depth from root (height of tree)
depths = nx.shortest_path_length(T, source=10)
height = max(depths.values())
print("Height:", height)           # 3

# Find leaf nodes (no successors)
leaves = [n for n in T.nodes() if T.out_degree(n) == 0]
print("Leaves:", leaves)

# Find root (no predecessors)
root = [n for n in T.nodes() if T.in_degree(n) == 0]
print("Root:", root)

nx.draw(T, with_labels=True)
plt.show()

Full Binary Tree Check

def is_full_binary_tree(tree_array):
    n = len(tree_array)
    for i in range(n):
        if tree_array[i] is None: continue
        left  = 2*i + 1
        right = 2*i + 2
        has_left  = left  < n and tree_array[left]  is not None
        has_right = right < n and tree_array[right] is not None
        if has_left != has_right:  # one child only → NOT full
            return False
    return True

tree = [1, 2, 3, 4, 5, None, None]
print(is_full_binary_tree(tree))   # True

Spanning Tree & Minimum Spanning Tree

Spanning Tree

A subgraph that includes all n nodes connected with exactly n−1 edges, no cycles. Keeps the graph connected with minimum edges.

Minimum Spanning Tree (MST)

The spanning tree with the smallest total edge weight. Algorithms: Prim's, Kruskal's. Used in networking to minimize cost.

MST with NetworkX (Prim's Algorithm)

G = nx.Graph()
G.add_weighted_edges_from([
    ('A','B',2), ('A','D',6),
    ('B','C',3), ('B','D',8),
    ('C','D',5)
])

MST = nx.minimum_spanning_tree(G, algorithm='prim')
print("MST edges:", list(MST.edges(data=True)))
# MST: A-B(2), B-C(3), C-D(5)  Total = 10

nx.draw(MST, with_labels=True)
plt.show()

BFS vs DFS

BFS — BREADTH-FIRST SEARCH

Explores nodes level by level. Uses a Queue (FIFO).

Good for: shortest path, level-order traversal, nearest-neighbour finding.

bfs = nx.bfs_tree(G, source=1)
print(list(bfs))
# Visits: 1 → neighbours → their neighbours…
DFS — DEPTH-FIRST SEARCH

Explores as deep as possible before backtracking. Uses a Stack (LIFO).

Good for: cycle detection, topological sort, exploring all paths.

dfs = nx.dfs_tree(G, source=1)
print(list(dfs))
# Visits: 1 → deep branch → backtrack

Full BFS/DFS Example

import networkx as nx
import matplotlib.pyplot as plt

G = nx.DiGraph()
G.add_edges_from([(1,3),(2,3),(1,4),(3,4)])

# BFS from node 1
bfs = nx.bfs_tree(G, source=1)
print("BFS order:", list(bfs))   # [1, 3, 4]

# DFS from node 1
dfs = nx.dfs_tree(G, source=1)
print("DFS order:", list(dfs))   # [1, 2, 4, 3, 5]

nx.draw(bfs, with_labels=True)
plt.show()
